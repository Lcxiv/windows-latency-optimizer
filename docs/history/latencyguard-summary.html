LatencyGuard

A desktop diagnostic tool that finds and fixes the hidden Windows settings causing gaming latency — built with Rust, PowerShell, and kernel-level tracing.

What It Is

LatencyGuard is a symptom-first diagnostic tool for competitive gamers. Instead of showing a dashboard of numbers, it asks "What are you experiencing?" — mouse freezing, frame drops, or sluggishness — then runs targeted diagnostics using kernel-level ETW traces, DPC/ISR analysis, and system registry audits to find the root cause.

Every finding is explained in plain English ("Your GPU interrupts are landing on the same core as your game thread, causing direct contention") with one-click fixes that capture before/after proof.

Diagnostic Tools & Techniques

Kernel-Level Tracing (ETW)

Uses Windows Performance Recorder (WPR) with custom .wprp profiles to capture Event Tracing for Windows (ETW) events. Captures HID input events at the kernel level to detect mouse input gaps — intervals between position reports that indicate driver-level stalls.

  • Input Latency Analysis — captures raw HID events, calculates inter-event timing, identifies gaps >4ms
  • DPC/ISR Analysis — measures Deferred Procedure Call and Interrupt Service Routine latency per driver
  • Driver Blame Attribution — correlates input gaps with DPC spikes to identify which driver (nvlddmkm.sys, storport.sys, etc.) caused the freeze

DPC Latency Profiling

Deep analysis of Deferred Procedure Call (DPC) latency using xperf ETW traces. Identifies drivers consuming excessive CPU time in deferred contexts, which directly causes frame stutters and input lag.

  • Per-driver breakdown — ranks drivers by max DPC time in microseconds
  • CPU core heatmap — shows interrupt distribution across all 16 logical CPUs (9800X3D)
  • CPU 0 contention detection — flags when interrupts pile on the OS scheduler core

GPU Performance Analysis

Checks GPU configuration (MSI mode, interrupt affinity, HAGS, ReBAR) and uses NVIDIA Nsight Systems for GPU-specific profiling.

  • MSI vs Line-Based Interrupts — detects shared IRQ contention
  • GPU DPC Health — nvlddmkm.sys DPC spikes >500us cause visible frame hitches
  • Nsight Systems Capture — 30-second GPU trace with timeline analysis

Network Diagnostics

Multi-server latency probing with bufferbloat detection:

  • Latency Probe — pings Cloudflare DNS, Epic Games servers, measures p50/p95/p99
  • Bufferbloat Detection — measures latency under load vs idle to detect queue bloat
  • Connection Quality Score — composite 0-100 score combining jitter, loss, and latency

Experiment Framework

Controlled A/B testing for system changes with automated before/after comparison:

  • 22 experiments run — each captures baseline, applies change, re-measures, stores JSON
  • Side-by-side comparison — score rings, delta cards, CPU heatmaps for before vs after
  • Rollback scripts — every fix generates a reversible rollback command

App Views

LatencyGuard has 4 main views. Screenshots captured with real data from a tuned gaming system (Ryzen 9800X3D + RTX 5070 Ti).

1. Symptom Picker (Landing Page)

Asks "What are you experiencing?" with 4 symptom cards. Each triggers a targeted diagnostic chain that only runs the relevant subset of 41 checks. Liquid glass design with colored accent borders.

2. Diagnostic Progress

Real-time step-by-step progress via Tauri event streaming. Shows which checks are running, with a determinate progress bar and checkmarks as steps complete. For Mouse Freezing, includes a 10-second ETW input capture.

3. Findings (Results)

Plain-English finding cards sorted by severity. Each card explains what's wrong, why it matters, and how to fix it. Mouse diagnostics show gap count, max gap duration, and blamed driver. One-click "Apply Fix" with before/after verification.

4. Expert Mode — Diagnostics Dashboard

Full data view: DPC driver blame bars, CPU interrupt heatmap (4x4 grid for 16 logical CPUs), system health metrics, frame distribution, stutter detection, mouse input health, and a filterable 41-check audit table. History tab with experiment comparison.
