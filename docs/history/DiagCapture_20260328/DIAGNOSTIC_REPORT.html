Step 1
GPU Driver Fires DPC
nvlddmkm.sys completes a GPU operation and queues a Deferred Procedure Call on cores 4-7
→
Step 2
CPU Stolen from Game
DPC execution at elevated IRQL preempts the game thread, preventing next frame submission
→
Step 3
GPU Idles at 25-40%
GPU has no work to do while waiting for the CPU to prepare and submit the next frame
→
Step 4
Frame Eventually Submits
Game thread regains CPU, submits a frame. GPU finishes fast (underutilized)
→
Step 5
Cycle Repeats
GPU completion fires another DPC, restarting the starvation loop
Aggravating factor: The 360 Hz monitor at 1440p forces continuous DWM (Desktop Window Manager) composition even at idle. At 360 Hz, DWM must composite a new frame every 2.78 ms, generating a sustained stream of GPU driver DPCs regardless of whether the game is rendering. This dramatically amplifies the feedback loop.

Remaining Recommendations

7 items
1
DDU + Clean NVIDIA Driver Reinstall
Use Display Driver Uninstaller (DDU) in Safe Mode to fully remove the current driver (v32.0.15.9597 / v595.97), then reinstall. This is the highest-impact action — the DPC regression in this driver version may be resolved by a clean installation or by trying an older/newer driver branch.
2
Consider 240 Hz Instead of 360 Hz
Reducing the monitor refresh rate from 360 Hz to 240 Hz decreases the DWM composition rate by approximately 33%, directly reducing the number of GPU driver DPCs generated per second.
3
Fortnite: Enable NVIDIA Reflex Low Latency = ON
NVIDIA Reflex synchronizes CPU frame submission with GPU readiness, reducing the render queue depth and breaking the DPC feedback loop by aligning work submission timing.
4
Fortnite: Set Rendering Mode to Performance or DX12
The Performance rendering mode reduces GPU draw calls and DPC generation. DX12 mode uses a more efficient command submission model that may reduce driver overhead.
5
Partition and Use the WD_BLACK SN850X for Games
Moving game installations to the secondary NVMe drive separates OS I/O from game asset loading, reducing storport.sys DPC contention on the primary drive during gameplay.
6
Install Proper ASUS Bluetooth Driver
If Bluetooth is needed in the future, install the ASUS-specific Bluetooth driver for the X670E-A board rather than relying on the generic Windows BTHUSB driver that crashes at boot.
7
Update Intel I226-V NIC Firmware
The boot-time link disconnect may be resolved by updating the Intel I226-V firmware/driver. Check Intel's download center for the latest version.
