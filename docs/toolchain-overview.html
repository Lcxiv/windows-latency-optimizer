1. Pipeline & Capture Scripts

The core capture infrastructure. pipeline.ps1 is the master orchestrator; everything else is a lighter alternative.

Script Parameters Purpose Tags
pipeline.ps1 -Label -Description -DurationSec (120) -GameProcess -SkipWPR -SkipPresentMon Master orchestrator. 8-phase capture: WPR trace → perf counters (11 metrics) → PresentMon frames → GPU (nvidia-smi) → network latency → xperf dpcisr → registry snapshot → experiment.json → dashboard update. Supports Quick (30s), Standard (120s), Deep (300s) modes. ADMIN WPR xperf
run_experiment.ps1 -Label -Description -DurationSec (120) -OutDir Lightweight experiment. Perf counters + registry snapshot only. No WPR/xperf. Faster for quick A/B comparisons. ADMIN
baseline_capture.ps1 -Label (default "BASELINE") Quick 10s snapshot. Perf counters (processor, DPC, interrupt, memory, disk, context switches) + MMCSS/Defender registry. Outputs formatted text file. ADMIN
reboot_capture.ps1 -Phase Before|After -DurationSec (10) Unified reboot A/B capture. Both phases: Razer status + GPU status + per-CPU counters + xperf DPC/ISR trace. -Phase After also verifies GPU affinity registry + finds latest baseline for comparison. Replaces separate before/after scripts. ADMIN xperf
health-check.ps1 None 60s health check. 7-component weighted score (0-100): DPC 25pts, bloat 20pts, SMI 15pts, memory 15pts, VRAM 10pts, BIOS 10pts, Defender 5pts. Generates self-contained HTML report and opens browser. ADMIN xperf
Which capture script to use?
  • Full experiment: pipeline.ps1 -Label X -Description Y (120s, all metrics)
  • Quick smoke test: pipeline.ps1 -Label X -SkipWPR -DurationSec 5
  • Fast A/B test: run_experiment.ps1 -Label X (no WPR/xperf)
  • 10s snapshot: baseline_capture.ps1
  • Before/after reboot: before_reboot_capture.ps1 → reboot → after_reboot_capture.ps1
  • Overall health: health-check.ps1 (HTML report)

Sourced by pipeline.ps1 and other scripts. Not run directly.

7. Dashboard

Self-contained HTML + vanilla JS. Works from file:// — no server needed.

Table View

All experiments in sortable table. Tag filter bar, checkbox selection for compare, metric timeline chart (line graph, switchable metric).

Columns: Name, Date, Tags, DPC%, Interrupt%, FPS, Frame Time p99, CPU%, Ping, Status

Detail View

Single experiment deep dive. Summary cards, DPC/ISR bar charts, per-CPU interrupt distribution, frame timing, GPU utilization, network latency, registry snapshot.

Charts: 10+ Chart.js instances per experiment

Compare View

Side-by-side comparison of 2+ experiments. Grouped bar charts for per-CPU metrics, frame time percentiles, FPS. Registry diff table.

10. Common Workflows

A) Full Experiment (Measure an Optimization)

1. pipeline.ps1 -Label "BEFORE" -Description "Pre-change baseline" 2. Apply change (run exp##_*.ps1 or manual) 3. Reboot if needed 4. pipeline.ps1 -Label "AFTER" -Description "Post-change measurement" 5. Open dashboard → Compare View → select both experiments 6. generate_dashboard_data.ps1 (auto-called by pipeline)

B) Audio Debugging

1. audio_diag.ps1 (quick triage, no admin) 2. invoke-elevated.ps1 -Script audio_fix_and_audit.ps1 -Arguments '-All' 3. fix_gpu_affinity.ps1 -Apply -KillRazer (route GPU off CPU 0) 4. invoke-elevated.ps1 -Script reboot_capture.ps1 -Arguments '-Phase Before' 5. Reboot 6. invoke-elevated.ps1 -Script reboot_capture.ps1 -Arguments '-Phase After' 7. Compare CPU 0 DPC% before vs after

C) Quick Health Check

1. health-check.ps1 (60s, opens HTML report) OR 1. audit.ps1 -Mode Quick (32 checks, generates fix script)

D) Mouse Stutter Investigation

1. diagnose-mouse.ps1 (10s HID capture) 2. analyze-input-latency.ps1 -EtlFile trace.etl (full pipeline) 3. analyze-dpc-deep.ps1 (correlate DPC drivers with input gaps) 4. Fix identified driver → re-test

E) Razer Cleanup + Affinity Fix

1. invoke-elevated.ps1 -Script disable_razer_startup.ps1 2. fix_gpu_affinity.ps1 -Apply (interrupt routing) 3. Reboot 4. invoke-elevated.ps1 -Script reboot_capture.ps1 -Arguments '-Phase After'

11. Optimization Recommendations

Consolidations Applied (2026-04-15)
  • before_reboot_capture.ps1 + after_reboot_capture.ps1 → reboot_capture.ps1 -Phase Before|After
  • 5 x run_*.ps1 wrappers → invoke-elevated.ps1 -Script <path>
  • Old scripts moved to scripts/_deprecated/ with migration notes
Also Deduplicated
  • exp21_msi_gpu_clocks.ps1: MSI section removed (now info-only check). Only does GPU clock locking. MSI managed by fix_gpu_affinity.ps1
  • exp12_nic_retuning_apply.ps1: NIC affinity section removed. Only does Nagle + WakeOnMagicPacket. Affinity managed by fix_gpu_affinity.ps1
Remaining Minor Overlap
  • audio_fix_and_audit.ps1 -CheckAffinity reads affinity registry (read-only) — overlaps with fix_gpu_affinity.ps1 -CheckOnly. Both are useful: audio_fix is audio-focused triage, fix_gpu is comprehensive. Low priority to merge.
Efficiency Improvements
  • Merge reboot captures into a single reboot_capture.ps1 -Phase Before|After to reduce duplication
  • Single elevation wrapper: Replace 5 run_*.ps1 scripts with Invoke-Elevated.ps1 -Script <path>
  • Pipeline quick mode already exists: pipeline.ps1 -SkipWPR -DurationSec 5 — use this instead of separate baseline_capture.ps1 when you want dashboard integration
  • Audit + Pipeline combo: audit.ps1 already loads the latest experiment.json if <24h old. Run pipeline first, then audit, and the HTML report includes experiment data automatically
  • Dashboard auto-update: pipeline.ps1 Phase 8 calls generate_dashboard_data.ps1 automatically. No need to run it separately unless editing curated experiments.js

Recommended Capture Sequence for Testing a Change

MOST EFFICIENT WORKFLOW 1. pipeline.ps1 -Label "BEFORE_X" -SkipWPR -DurationSec 30 (Quick capture: perf + GPU + network + xperf + registry + dashboard update) 2. Apply your change (run exp script) 3. Reboot if needed 4. pipeline.ps1 -Label "AFTER_X" -SkipWPR -DurationSec 30 (Same capture for A/B comparison) 5. Open dashboard → Compare → done WHY THIS IS BETTER: - One script handles everything (no separate baseline + generate_dashboard + etc.) - Results automatically appear in dashboard - 30s is enough for DPC/ISR + perf counters - Skip WPR unless you need ETL deep-dive later - Skip PresentMon unless measuring frame timing
