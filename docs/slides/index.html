03 · PROBLEM
The symptom
Symptom

Cursor hitches mid-fight. Frames are smooth.

The game ran at a solid 240 fps. The cursor froze for 10 ms every few seconds. Short enough that no monitoring tool flagged it. Long enough to throw aim in a Fortnite duel.

Task Manager said the CPU was at 12 %. LatencyMon's summary said the system was "suitable for real-time audio". Both were technically correct and entirely useless.

The averages were fine. The averages were also the wrong measurement.

04 · PROBLEM
Why "optimization guides" fail
The missing layer

Every guide skips the measurement step.

What every guide says

  • Disable Nagle's algorithm
  • Flip 20 registry keys
  • Change power plan
  • Update drivers
  • (No evidence either way)

What's actually missing

  • Did your system have this problem?
  • What changed after the fix?
  • Did the fix regress anything else?
  • How do you roll back if it broke?

05 · HYPOTHESIS
The interrupt path
Hypothesis

The stutter is on the interrupt path, not in user space.

Game smooth + cursor freezing ⇒ rules out application CPU contention, GPU saturation, memory pressure. Leaves interrupts and DPCs.

// Mouse arrival at kernel
USB controller  →  IRQ  →  CPU n  →  ISR
                                            ↓ defers
                                       DPC queued
                                            ↓ runs at DISPATCH_LEVEL
                                       cursor coord → user space

// Any stall here = input gap.
// If CPU n is saturated with other interrupts, the DPC waits.
06 · METHOD
Capture pipeline
Method · Layer 1

One PowerShell script captures the full state.

scripts/pipeline.ps1 runs:

  • WPR — 60s ETW trace (CPU, DPC, GPU, HID)
  • xperf — separate DPC/ISR attribution
  • perf counters @ 1 Hz per logical CPU
  • nvidia-smi snapshots, GPU sensors
  • PresentMon frame timing (optional)
  • Registry + WMI snapshot of 41 settings

13 · RETROSPECTIVE
What I'd change
Retrospective

What worked. What I'd do differently.

What worked

  • Numbered experiments with hypothesis + rollback
  • Per-CPU measurement, not _Total
  • PowerShell over Python — no runtime, ships with Windows
  • Negative results kept and labeled

What I'd do differently

  • Real-time monitor on day one (took two months)
  • Skip the Tauri layer — HTML + Chart.js was enough
  • Pester tests on the audit logic earlier
  • Capture a clean baseline before each major OS update
14 · TAKEAWAY
The shape that generalized
Pattern

Diagnose. Explain in plain English. Provide the rollback.

This shape — diagnostic tool that produces actionable findings with reversal commands — has shown up in my BI work since. It beats a dashboard that asks the viewer to be the analyst.

A dashboard answers "what's happening?" A good one also answers "what do I do about it?"
