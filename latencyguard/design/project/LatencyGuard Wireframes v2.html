Kernel-level measurement

Microseconds, not vibes. Every scan is a measurement you can defend.

LatencyGuard runs a 10-second ETW capture at the HID layer, calculates inter-event timing, and correlates each gap with the driver holding the DPC queue in that window. You don't get a score — you get a number, a unit, and a name.

  • HID input events at microsecond precision
  • Per-driver DPC/ISR attribution — with blame
  • Before & after traces for every applied fix
  • Exportable raw ETL for Windows Performance Analyzer
Experiment history

Every fix leaves a trace. Rollback any one. Compare any two.

Most optimizers fire 20 registry edits at your machine and hope. LatencyGuard treats each change as an experiment — with a before snapshot, an after snapshot, and a one-click rollback. Your system gets measurably faster, and you can prove it.

  • Every apply writes a reversible snapshot
  • A/B compare any two runs, side-by-side
  • Share an experiment ID with a friend, they can re-run
  • Export the full timeline as a signed HTML report
For power users

Command mode. Density when you want it, silence when you don't.

No "Simple / Expert" toggle. Command is a full-canvas mode that drops the hand-holding: live capture, per-driver DPC bars, the full 41-check grid, and a batched-fix tray you can apply in one go. Keyboard-first, mouse-second.

  • ⌘K palette · all actions, anywhere
  • Batched apply — review, then ship
  • Light + Dark · auto-match system
  • Export .etl for Windows Performance Analyzer
